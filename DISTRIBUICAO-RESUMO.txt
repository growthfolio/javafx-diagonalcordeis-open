✅ SOLUÇÃO IMPLEMENTADA PARA LINUX → WINDOWS

1. COMPILAR NO LINUX:
   ./build-installer.sh

2. RESULTADO:
   target/dist/DiagonalCordeis-1.0.0.zip (98 MB)

3. ENVIAR AO CLIENTE (Windows)

4. CLIENTE PRECISA:
   - Java 21: https://adoptium.net/
   - Descompactar ZIP
   - Executar: DiagonalCordeis.bat

================================================================================

📁 LOCALIZAÇÃO DOS ARQUIVOS (no cliente Windows):

Aplicação:      Onde o cliente descompactar (ex: C:\Aplicativos\DiagonalCordeis\)
Banco de Dados: %APPDATA%\DiagonalCordeis\data\diagonalcordeis.db
                (C:\Users\<usuario>\AppData\Roaming\DiagonalCordeis\data\)

✅ Banco separado da aplicação (seguro!)
✅ Não é deletado se reinstalar
✅ Backup simples: copiar arquivo .db
